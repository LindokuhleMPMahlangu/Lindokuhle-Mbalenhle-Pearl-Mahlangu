# Pearl Mahlangu — Portfolio

A responsive personal portfolio for Lindokuhle Mbalenhle Pearl Mahlangu, built with
plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

The portfolio includes responsive navigation, filterable skill cards, an expandable
education list, and prefers-reduced-motion support. Update the GitHub and LinkedIn
links in `index.html` if the preferred profile URLs change.
